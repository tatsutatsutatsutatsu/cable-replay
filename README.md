# 配線リプレイ

テレビ、ルーター、ゲーム機、PCデスク周りなどを外す前に、**戻し方を残す**ための完全オフラインWebアプリです。

## 使い方

1. `cable-replay.html` をブラウザで開きます。
2. 配線を外す前の写真を選択します。
3. 写真上の端子をクリックして、名前と色を登録します。
4. ケーブルの両端を選び、外す順に接続を登録します。
5. 「復旧モード」で、登録した順序を逆から一手ずつ確認します。

## 特長

- サーバー・アカウント・外部ライブラリは不要
- 写真、端子、接続順は端末内に保存
- 端子を色と名前で写真に重ねて表示
- 接続順の入れ替えと、逆順の復旧ガイド
- JSON形式でのバックアップ／復元
- 写真付きの印刷ガイド

## 注意

- 壁内配線、電源工事、機器の分解には使わないでください。
- 発熱、破損、異臭がある機器は接続を中止し、公式の案内または専門家を確認してください。
- `file://` で直接開いたHTMLのブラウザ保存領域は環境によって差があるため、重要な記録は「書き出し」でバックアップしてください。
